# BiuCrypt

> Public portfolio record — source code, program screenshots, binaries, protected formats, cryptographic construction details, and sensitive implementation details are intentionally not published here.

BiuCrypt is a focused desktop project for protecting files and folders through a clear, controlled workflow. It explores how file protection can remain understandable before, during, and after an operation.

[View the case study on biuret.dev](https://biuret.dev/sites/biucrypt.html)

## Selected highlights

- **Guided protection** — keeps important choices visible throughout the workflow.
- **Integrity-aware handling** — uses validation and clear feedback around protected content.
- **Controlled operations** — makes progress and cancellation states understandable.

## What this project demonstrates

BiuCrypt reflects ongoing practice in applied cryptography, safe file handling, validation, desktop UX, and recovery-aware product thinking. Cryptographic construction, protected formats, validation rules, and recovery behavior are intentionally omitted.
